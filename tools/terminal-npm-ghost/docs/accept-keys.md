# Accept keys cheatsheet

## fish (recommended)

| Want | Press |
|------|-------|
| Take the gray ghost suggestion | **→** (Right Arrow), End, or Ctrl-F |
| Take first word only | Alt-→ / Alt-F |
| Complete `npm run <script>` from package.json | Type `npm run ` then **Tab** |

## zsh-autosuggestions

| Want | Press |
|------|-------|
| Accept suggestion | **→** (default) |
| npm scripts | Tab after `npm run ` |

## ble.sh (bash)

| Want | Press |
|------|-------|
| Accept auto-complete ghost | **→** / Ctrl-F / End at EOL |
| npm scripts | Tab (see npm-script-ghost) |
